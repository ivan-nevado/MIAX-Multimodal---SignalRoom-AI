# Typical earnings-call structure

1. Operator introduction and safe-harbour statement (forward-looking statements disclaimer).
2. CEO remarks: strategy, highlights.
3. CFO remarks: revenue, margins, segment results, cash flow, guidance.
4. Q&A with analysts: watch for repeated questions (= market concern) and evasive answers.
5. Closing remarks.

Signals worth extracting: guidance changes vs prior quarter, margin commentary, demand/supply language,
capital return (buybacks/dividends), regulatory/geopolitical commentary.
