# Valuation reference

SignalRoom does not produce price targets or fair values. When valuation is discussed:

- Mention valuation only when evidence (news, analyst actions, documents) explicitly raises it.
- Typical framings: "valuation concerns", "multiple compression", "priced for perfection".
- High recent returns + negative surprise is *consistent with* valuation sensitivity; it is not proof.
- Never compute P/E or similar multiples unless both inputs are provided by deterministic data.
