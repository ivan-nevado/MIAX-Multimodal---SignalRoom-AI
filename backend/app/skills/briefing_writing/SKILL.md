# Briefing writing

**Structure:** greeting → headline → 2-4 sentence summary → up to 4 numbered items (title, body,
"why it matters", sources) → risk flags → macro context.

**Voice:** calm, confident, analytical, never sensationalist. Short sentences that work when read aloud.
Avoid tables, symbols and long numbers in the spoken script ("down about two percent" reads better than
"-2.137%"); the written version may keep exact figures.

**Rules:** only data provided; hedge explanations; no recommendations; every item cites source ids.
